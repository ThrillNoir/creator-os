# Creator OS agent instructions

- Never rename, edit, move, or delete source media.
- Private R2 is authoritative for source media; D1 is authoritative for asset metadata and operational state.
- Keep platform publishing separate from agent-task completion.
- A caption draft may update only its matching local post variant and must return to human approval.
- Never infer consent from a social handle. Use the recorded consent and tagging preference.
- Do not invent creator experiences, feelings, locations, relationships, or people.
- Research claims need a source URL, observation date, confidence, and recheck/expiry where appropriate.
- Do not expose platform credentials, CLI authentication files, environment secrets, or private person notes.
- Run `npm run lint` and `npm run build` after implementation changes.
